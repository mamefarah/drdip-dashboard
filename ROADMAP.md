# Roadmap and Public Benefit

## Purpose

DRDIP Dashboard supports development-programme monitoring and reporting for Somali Region rural-development activities, including target-versus-collected indicator tracking, charts, filters, and geographic data views.

## Intended users

Programme coordinators, monitoring and evaluation (M&E) officers, and development partners who need a clear, visual view of programme indicators and progress.

## Roadmap (next 6 months)

- Improve data validation and error handling for Kobo data imports
- Expand automated tests for chart rendering and data loaders
- Add offline-friendly and low-bandwidth support for field use
- Improve accessibility and mobile responsiveness
- Document data privacy handling and anonymization practices
- Add a public changelog and versioned releases
